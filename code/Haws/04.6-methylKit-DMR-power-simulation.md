# 04.6 methylKit region-level power simulation

**Question:** the DSS per-CpG simulation ([04.4-DSS-power-simulation.md](04.4-DSS-power-simulation.md)) found that a single CpG needs a difference of about 20 points before the experiment can tell it from chance. Oyster methylation changes are more likely to cover whole gene bodies or blocks. Pooling the reads of a region raises coverage, so does testing regions with methylKit `MN` (as in 04.6) detect smaller differences?

## Approach

Same idea as the DSS simulation: known differences are spiked into the **real region counts**, with the **real labels**, so each oyster's own variation and the genetic outliers are kept.

- **Region sets:**
  - `tile1000`: non-overlapping 1 kb windows, ≥ 3 CpGs.
  - `gene`: whole gene bodies.
  - Both use the 04.6 primary settings: ≥ 10 reads per region in each oyster, high-coverage filter at the nuclear 99.9th percentile, all 24 oysters, coverage in all samples, `MN`.
- **Spikes:**
  - **Number:** per term, 1,000 windows (0.24% of 424k) or 300 genes (0.9% of 34k).
  - **Which regions:** nuclear regions with ≥ 10 reads in every oyster (so they pass the coverage filter and are tested), with pooled methylation of 15–85%. Each region gets a random direction.
- **Binomial thinning of the summed reads.** At a spiked region with pooled methylation *m*, oysters on the "up" side have each unmethylated read switched to methylated with probability (Δ/2)/(1 − *m*). Oysters on the "down" side have each methylated read switched with probability (Δ/2)/*m*. Coverage is unchanged. This is applied after `reorganize` and before `filterByCoverage` and `normalizeCoverage`, so the spiked data go through the same steps as the real data.
- **Grid:** Δ ∈ {2, 5, 10, 15, 20, 30} percentage points × 10 replicates, for each region set. Only the ploidy and pH tasks with coverage in all samples are run (array tasks 1 and 4).
- **Null:**
  - **Genes:** the 100 free permutations from 04.6, which already have per-gene p-values.
  - **Windows:** the 04.6 window permutations kept only counts. 50 permutations (seeds 1–50, tasks 1 and 4) are rerun, saving the sorted p-values. Seeds 1–20 reproduce the existing counts.

## Detection rules

1. **DMR:** methylKit q < 0.05 and |Δ| ≥ 10 (the fixed 04.6 DMR definition). Also q < 0.05 at any |Δ|.
2. **Empirical FDR < 0.05:** the largest p-value cutoff where (mean permuted count below it) / (simulated count below it) ≤ 0.05.
3. **Experiment-level:** is the run's DMR count (or q-only count) above the 95th percentile of the permutation counts?

## How to run

```bash
OUT_DIR=<checkout with prep files>/analyses/Haws_04.6-methylKit-DMR   # only needed from a git worktree
REGIONS=tile1000 ARRAY=1,4 PERM="$(seq 1 50)" bash 04.6-methylKit-DMR-slurm-submit.sh   # window null with p-values
for d in 2 5 10 15 20 30; do for r in $(seq 1 10); do
  REGIONS=tile1000 SIM_DELTA=$d SIM_REP=$r bash 04.6-methylKit-DMR-slurm-submit.sh
  REGIONS=gene SIM_N=300 SIM_DELTA=$d SIM_REP=$r bash 04.6-methylKit-DMR-slurm-submit.sh
done; done
REGIONS=tile1000 bash 04.6-methylKit-DMR-slurm-submit.sh simsummary
REGIONS=gene bash 04.6-methylKit-DMR-slurm-submit.sh simsummary
```

Outputs go to `analyses/Haws_04.6-methylKit-DMR/power-simulation/`: `power-runs-*.csv`, `power-summary-*.csv`, and `power-curves-*.png`.

## Limitations

- **Every CpG gets the same expected shift.** Within a region, each read is switched with the same probability, so the coverage-weighted region methylation moves by Δ/2 in each group. Real effects may be concentrated in part of a region.
- **Effects are uniform within a group.** Variation between oysters in the size of the effect would lower power. So, as for DSS, these numbers are a best case.
- **Gene bodies above 85% methylation are excluded from the spikes.** Many highly methylated oyster genes fall above that, and their power would be somewhat different.
- **Read-level dependence isn't simulated.** Summed region counts count a read once per CpG it covers. Reads are switched independently, which is the same independence methylKit assumes when it tests the counts.
